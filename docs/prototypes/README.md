# FDDP Architecture Prototypes

This directory stores early architecture design snapshots for reference.

These documents are useful for understanding the original FDDP design direction, but they are not the current SDK/runtime API specification. For current usage, start from the repository root `README.md`, `packages/go-fddp/README.md`, and `packages/nextjs-sdk/README.md`.

## Files

- `fddp-architecture-prototype-v9.md`: Markdown source of the v9 architecture prototype.
- `fddp-architecture-prototype-v9.pdf`: PDF export of the same prototype.
- `fddp-architecture-prototype-v9.docx`: editable document export of the same prototype.
